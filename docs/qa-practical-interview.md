# QA 실무 면접 정답지

응시자에게 이 문서를 주지 않습니다. 사이트 어디에서도 링크하지 않습니다.

응시자에게 줄 주소는 스토어프론트 `/qa-test` 입니다. 가입 과제는 계정을 만들지 않습니다. `POST /auth/register`를 호출하지 않습니다.

각 과제에 심어 둔 문제는 두 개입니다. 빈 값, 수량 0, 새로고침은 정상 동작입니다.

## 가입 `/qa-test/signup`

이름, 올바른 이메일, 8자 이상인 서로 다른 비밀번호와 비밀번호 확인을 입력하고 제출합니다.

1. 비밀번호와 확인이 달라도 완료 화면으로 넘어갑니다.
   - 기대: 확인이 일치할 때만 완료됩니다.
   - 실제: 서로 다른 8자 이상 비밀번호로도 완료 화면이 나옵니다.
   - 심각도: 높음
2. 완료 화면의 이메일은 입력한 주소의 마지막 글자가 빠져 있습니다. 이름은 입력값 그대로입니다.
   - 기대: 입력한 이메일이 그대로 보입니다.
   - 실제: 예를 들어 `qa@example.com`은 `qa@example.co`로 보입니다.
   - 심각도: 높음

빈 이름, 빈 이메일, 잘못된 이메일, 8자 미만 비밀번호는 제출되지 않고 필드 오류가 보여야 합니다.

## 장바구니 `/qa-test/cart`

상품은 블랙 밴드 4800센트, 화이트 코드 3600센트입니다. 처음 수량은 각 1개입니다.

1. 수량을 올려도 줄 금액은 1개 가격에 머뭅니다. 소계도 남은 상품의 1개 가격만 더합니다.
   - 기대: 줄 금액과 소계는 단가 × 수량입니다.
   - 실제: 수량이 2여도 줄 금액은 단가와 같습니다.
   - 심각도: 높음
2. 상품을 지워도 제목 아래 개수는 2로 남습니다. 두 개를 모두 지우면 빈 목록 문구가 나오지만 개수는 그대로 2입니다.
   - 기대: 개수는 남아 있는 줄 수와 같습니다.
   - 실제: 개수는 처음 값 2에서 바뀌지 않습니다.
   - 심각도: 중간

수량은 1 아래로 내려가지 않습니다. 새로고침하면 처음 두 줄로 돌아갑니다. 이 장바구니는 `juspeace-cart`에 저장되지 않습니다.

## 배송 `/qa-test/shipping`

상품 합계는 8400센트입니다. 일반 배송은 800센트, 빠른 배송은 1800센트입니다. 처음 선택은 일반 배송입니다.

1. 전화번호에 문자를 넣어도 받는 사람과 주소가 있으면 계속 진행됩니다.
   - 기대: 전화번호는 숫자만 허용하고, 문자가 있으면 막습니다.
   - 실제: `12ab34` 같은 값으로 완료 화면까지 갑니다.
   - 심각도: 중간
2. 빠른 배송을 고르면 방법 이름은 빠른 배송으로 바뀌지만, 배송비와 총액은 일반 배송 800센트를 그대로 씁니다. 총액은 9200센트입니다.
   - 기대: 빠른 배송의 배송비 1800센트가 총액에 반영되어 10200센트입니다.
   - 실제: 라디오의 빠른 배송 금액과 요약의 배송비·총액이 다릅니다.
   - 심각도: 높음

받는 사람, 전화번호, 주소가 비어 있으면 제출되지 않습니다. 새로고침하면 일반 배송으로 돌아갑니다.
